# Beta features

A feature marked **Beta** is still being tested. Its interface, behavior, or stored configuration may change, and it may contain bugs that are not present in stable features.

Before using a Beta feature:

- test it with supervision and in a low-risk environment;
- keep backups of profiles, CaveBot files, and scripts it may modify;
- do not assume settings from another client version or OTServer behave identically;
- record the ZeroBot version, client version, server, and reproducible steps when reporting a problem.

Avoid relying on Beta behavior for high-risk or unattended gameplay until it has been validated with the exact character, route, client, and server combination that will use it.

The **Beta** label applies only where it is shown in ZeroBot or its documentation; it does not imply that every ZeroBot module is in Beta.
